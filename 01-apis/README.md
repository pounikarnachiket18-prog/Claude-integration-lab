# 01 – APIs

**What it is:** An API (Application Programming Interface) is a way for one program to talk to another. The Claude API lets *your* code send a message to Claude and get a reply back, the same way you chat on claude.ai, but from a script.

**What you'll learn here:**
- What a request and a response look like
- What an API key is and how to keep it secret
- How to send your first message to Claude from code
