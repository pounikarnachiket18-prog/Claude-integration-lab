# 02 – MCP Servers

**What it is:** MCP (Model Context Protocol) is a standard "plug" that lets Claude use outside tools and data, like reading files, searching a database or checking a calendar. An *MCP server* is a small program that offers those tools to Claude.

**Analogy:** If Claude is a smart assistant, MCP servers are the apps on its phone.

**What you'll learn here:**
- What tools, resources and prompts are in MCP
- How to build a tiny MCP server (for example, a "say hello" tool)
- How to connect it to Claude
