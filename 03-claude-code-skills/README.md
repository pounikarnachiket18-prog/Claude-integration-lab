# 03 – Claude Code Skills

**What it is:** Claude Code is Claude working as a coding assistant in your terminal or editor. A *skill* is a packaged set of instructions (a `SKILL.md` file, plus optional helper files) that teaches Claude Code how to do a specific task your way, such as "write commit messages like this" or "review code with this checklist."

**Analogy:** A skill is a recipe card you hand to Claude.

**What you'll learn here:**
- How a skill folder and its `SKILL.md` file are laid out
- How Claude decides when to use a skill
- How to write your own simple skill
