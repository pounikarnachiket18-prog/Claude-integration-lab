# 05 – AI Agents

**What it is:** An *agent* is Claude working in a loop: it gets a goal, decides on a step, uses a tool, looks at the result, and repeats until the goal is done. A chatbot gives one answer; an agent takes actions.

**This is where everything comes together:** agents use APIs (01), often get their tools from MCP servers (02), can follow skills (03), and can work on GitHub (04).

**What you'll learn here:**
- The agent loop: think → act → observe → repeat
- What "tool use" means
- How to build a very small agent safely
