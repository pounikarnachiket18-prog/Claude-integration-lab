# 06 – AI Video

**What it is:** Learning to make cinematic videos with Claude Code's help.
Claude acts as a director's assistant: it writes scripts, plans shots,
writes code that makes video, and edits clips together.

## The three ways to make the footage

| Way | How | Cost |
|---|---|---|
| 1. Made with code | Claude writes code that draws every frame (Remotion, FFmpeg) | Free |
| 2. Edit existing material | Your own photos/clips, free stock footage, optional AI voice | Free or cheap |
| 3. AI-generated footage | Type a description, an AI service creates a short clip (Veo, Kling, Runway, Luma) | Paid |

We start with Ways 1 and 2 (free). Way 3 comes later, only when chosen.

## The filmmaking steps we'll practice

1. **Idea**: one sentence about the video
2. **Script**: what happens and what is said
3. **Storyboard**: a plan of every shot
4. **Footage**: the pictures and clips
5. **Titles**: text and animations
6. **Edit**: join everything, add music
7. **Export**: save the finished video

## Rules for this folder

- Save the **code and plans** that make videos, not big video files.
  (GitHub rejects files over 100 MB, and big files slow the repo down.)
- Only use footage, music and images you're allowed to use.
- Never put API keys in any file here.

## Words to know

- **Frame**: one still picture. Videos show many frames per second (often 30).
- **Clip**: a short piece of video.
- **Storyboard**: a comic-strip-style plan of every shot.
- **Render**: turning a project or code into a video file.
- **Export**: saving the final video to watch or share.
